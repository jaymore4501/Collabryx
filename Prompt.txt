# Core Functional Requirement

Build an anonymous collaboration system where:

1. User clicks “Create Board”
2. Board is instantly created
3. Unique shareable board URL is generated
4. User sends link to others
5. Anyone with link joins instantly
6. No authentication required
7. All users edit together in real-time
8. All changes sync instantly
9. Cursors sync instantly
10. Activity feed updates instantly

Temporary Board Lifecycle:

Important:

Boards must be temporary.

Lifecycle logic:

* Board exists only while at least one participant is active.
* When the last user closes tab/browser/leaves board:

  * delete board document
  * delete all elements
  * delete all sessions
  * invalidate board URL
* If user revisits deleted link:
  show:
  “This collaboration session has expired.”

Implement this with:

Socket disconnect detection
Last active participant detection
Auto cleanup worker

Board expiration conditions:

Condition 1:
All users disconnected

Condition 2:
No heartbeat for 2 minutes

Condition 3:
Window/tab closed
